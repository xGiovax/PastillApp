# PastillApp - Gestor, Registro y Recordatorio de Medicamentos 

**PastillApp** es una aplicación móvil diseñada para ayudar a los usuarios a llevar un control eficiente de su toma de medicamentos, permitiendo registrar tratamientos, configurar alarmas de recordatorio y gestionar sus horarios de forma sencilla.

## Características Principales

- **Registro de Usuarios:** Autenticación y gestión de cuentas mediante Firebase Authentication.
- **Gestión de Medicamentos:** Registro de dosis, nombres y horarios de medicamentos.
- **Recordatorios:** Notificaciones y alertas oportunas para cada toma.
- **Interfaz Intuitiva:** Diseño limpio centrado en la facilidad de uso del paciente.
